# Linea

Сайт студии Linea: одна страница `index.html` с сайтом и встроенной админ-панелью.

## Как редактировать сайт
1. Открой сайт и зайди в админку: адрес `#/admin` или 5 быстрых кликов по логотипу.
2. Внеси правки (кейсы, услуги, тексты, контакты, политика студии).
3. Нажми «Скачать сайт» — получишь обновлённый `index.html`.
4. Замени `index.html` в этом репозитории и сделай commit — GitHub Pages обновит сайт.

## Важно
- Правки в админке хранятся только в браузере, пока не скачан и не загружен новый `index.html`.
- Репозиторий публичный: весь код виден всем. Не добавляй в админке личные токены и реквизиты, которые нельзя показывать.
